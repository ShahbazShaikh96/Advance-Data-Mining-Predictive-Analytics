# Advanced Data Mining and Predictive Analytics

This repository contains applied predictive analytics coursework focused on supervised modeling, model comparison, and business-oriented interpretation. The folders have been renamed to describe the work directly rather than the original assignment labels.

## Projects

| Project | Focus | Key Methods |
| --- | --- | --- |
| [Loan Default Loss Prediction](./01_Loan_Default_Loss_Prediction) | Two-stage credit risk modeling for default likelihood and loss severity | Classification, regression, imputation, scaling, model validation |
| [SVM and Neural Network Regression](./02_SVM_and_Neural_Network_Regression) | Sales prediction using support vector machines and neural networks | Cross-validation, hyperparameter tuning, caret modeling |

## Repository Notes

- Files are preserved as coursework artifacts, with clearer names added for portfolio readability.
- Raw loan datasets are not included. The loan modeling notebook expects local CSV files in a `data/` folder when rerun.
- Rendered reports are included where available so reviewers can inspect the analysis without rebuilding the environment.
