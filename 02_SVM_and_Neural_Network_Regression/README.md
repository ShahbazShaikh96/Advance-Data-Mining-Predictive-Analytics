# SVM and Neural Network Regression

This project compares support vector machine and neural network approaches for predicting sales using the `Carseats` dataset from the ISLR package.

## What This Project Contains

- `SVM_and_Neural_Network_Regression.Rmd`: R Markdown workflow for data preparation, model training, cross-validation, tuning, and prediction.
- `SVM_and_Neural_Network_Regression_Report.pdf`: Submitted report/output.
- `SVM_and_Neural_Network_Regression_Instructions.pdf`: Original assignment prompt retained for context.

## Methods Used

- Feature selection from the ISLR `Carseats` dataset
- Linear support vector machine regression
- Repeated cross-validation
- Hyperparameter tuning for SVM cost values
- Neural network regression with centered and scaled predictors
- New-record sales prediction

## Review Notes

The project is intentionally lightweight and reproducible because it relies on the public ISLR package dataset rather than external CSV files.
